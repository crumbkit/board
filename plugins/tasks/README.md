# tasks

A Board plugin that extracts each `lr/task/v1` record's title, status and due
date into its database, and offers `due`: the open tasks due before a date.

Install it from this checkout:

    uv sync --frozen --no-dev
    ln -s "$PWD" "${XDG_DATA_HOME:-$HOME/.local/share}/board/plugins/tasks"

Then enable it in a board's `.board/board.json` with `"plugins": ["tasks"]`.
`board call tasks.due` takes `{"before": "YYYY-MM-DD"}`. `board query` can join
`p_tasks.tasks` (`blob`, `title`, `status`, `due`) with `entries` on `blob`.

The gates, which CI runs: `uv run ruff format --check .`, `uv run ruff check .`,
`uv run pyright` and `uv run pytest`. The tests drive `$BOARD_BIN`, by default
the workspace's `target/debug/board`, so build it first with
`cargo build -p board-cli`. `plugin.json` is generated by
`uv run python -m board_tasks.manifest`, and a test checks it is up to date.
