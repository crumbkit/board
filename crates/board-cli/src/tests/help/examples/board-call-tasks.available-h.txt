Sync the repos the caller's remote chooses, then list their open tasks available now, those due within seven days, and the stale ones.

Usage: board call tasks.available [OPTIONS]

Options:
      --context <context>  Only tasks tagged with this context, such as errands.
      --remote <remote>    A git remote, or owner/name, to choose the repos by in place of the origin of the directory board was started in.
      --repo <repo>        One repo's tasks: / for the board's own tree, or a notes repo's mount path such as /repos/notes-personal; the caller's git remote chooses the repos when left out.
  -h, --help               Print help (see more with '--help')

Without a flag, Board reads the input as JSON on stdin; with one, it ignores stdin.

Examples:
  board call tasks.available

Global flags: --json. `board call tasks.available --help` describes them.
