ok      controls  0.1.0    false    ["for-path","check","evaluate"]                               The controls plugin keeps requirements on files as records in the board that holds the files. Use it when you start work in a board or a repository it mounts, and before you edit a file a control may govern. Start with `board -C <board> call controls.check --path /<directory>`, which lists the budgets it measures and the written requirements under that path. `board -C <board> call controls.for-path --path /<file>` lists the controls on one file. SKILL.md and README.md in the plugin's directory say more.
ok      evals     0.1.0    false    ["about","open"]                                              Record every test of a library, tool, model or agent as an eval and its runs in the board, and check what was already tested before testing. Use it before you start a test and when you conclude one. Start with `board -C <board> call evals.about --subject <name>`, which lists the evals of what you will test. `board -C <board> call evals.open` lists those still planned or running. SKILL.md and README.md in the plugin's directory say more.
ok      plans     0.1.0    false    ["open"]                                                      Questions an agent session asks the owner, the owner's answers, and the decisions sessions record. `board call plans.open` lists the questions still waiting for an answer, oldest first. plugins/plans/README.md in Board's repository says where each record lives.
ok      requests  0.1.0    false    ["thread"]                                                    A plugin's request to the owner as a thread: every version of a pending effect, the owner's answers and the owner's replies. Run `board --personal call requests.thread --effect <id>` with any version's id. docs/plugins/built-in/requests.md in Board's repository says where a reply lives.
ok      tasks     0.3.0    false    ["available","add","claim","done","defer","drop","reviewed"]  Sweep the person's tasks one at a time, marking each done, deferring, dropping or editing it, and add a task. Use it when the person asks to sweep, review or go through their tasks or to-do list, or to add a task to their own list. Start with `board -C <board> call tasks.available`, run in the repository you work in, which syncs the notes repos that repository's git remote routes to and lists the tasks to sweep. SKILL.md and README.md in the plugin's directory say more.
