decisions.open disabled The decisions under a path that an open question asks the owner to review, oldest first.
evals.about disabled The evals that name a subject, or that name a repository's repo record or live in its mount, whatever their status, here and in mounted boards.
evals.open disabled The evals still planned or running, here and in mounted boards.
plans.open disabled The questions under a path whose status is open, oldest first.
requests.thread disabled Every version of the effect's request, oldest first, with its answer, and the owner's replies to them, oldest first.
tasks.available disabled Sync the repos the caller's remote chooses, then list their open tasks available now, those due within seven days, the stale ones, and those an owner holds.
tasks.add disabled Write a new open task to tasks/<slug>.md in the repo the caller's remote routes to. It syncs the task's repo first and pushes after, and sets reviewed.
tasks.claim disabled Claim an open task for an owner, refused when another owner holds it. It syncs the task's repo first and pushes after, and sets reviewed.
tasks.done disabled Mark a task done, or defer a repeating one to its next occurrence. It syncs the task's repo first and pushes after, and sets reviewed.
tasks.defer disabled Defer a task until a date or a horizon from today, written as a date. It syncs the task's repo first and pushes after, and sets reviewed.
tasks.drop disabled Mark a task dropped. It syncs the task's repo first and pushes after, and sets reviewed.
tasks.reviewed disabled Mark a task reviewed today. It syncs the task's repo first and pushes after, and sets reviewed.
